# 通用默认偏好说明

跨业务约定。业务具体值写在各 `domains/<biz>/ui.defaults.md`。

## 取值优先级（大原则，强制）

```text
1. 用户本轮显式指定（对话 / scoped 点名 / form 入参）
2. 矩阵轴当前行的值（full/scoped 笛卡尔积）
3. 业务 defaults（含「有不限则不限」——仅当该字段未被 1/2 指定）
4. explore options[0] / prefer_or_first
```

- **defaults 不得覆盖用户/矩阵已给出的具体值**（例如用户指定负责人=谈鑫时，禁止再自动改成「不限」）。
- 指定值不在 options → 降级并记 report「偏好偏差」（优先「不限」若有，否则 options[0]），尽量继续。

## 规则名

- Pattern：`auto_dc_{timestamp}`（或业务文档指定的等价唯一 pattern）
- 每条用例必须唯一，供列表定位与断言

## 未点名字段

1. 读业务 defaults  
2. 非必填且无「填」要求 → 不填  
3. 选项含「不限」→ 选不限  
4. 仍必填 → `prefer_or_first`（偏好值优先，否则 options[0]）

## 冲突：不中断整批

- 偏好/指定不在 options → 降级并记 explore/report「偏好偏差」，继续生成其它行  
- 仅当单行无法完成「确认」且无合法填法 → 该行标记跳过，其它行继续

## 缺字段：跳过

- 换维度等导致控件不存在 → 不填、不 blocker 整批

## 随机数

- 若 defaults 要求区间 random：生成矩阵时取整型，写入该行 `form`，保证可复现于单次矩阵文件

## 读取顺序（文档层）

1. 本文件（通用优先级与未点名规则）  
2. 业务 `*.defaults.md`（可覆盖同名默认**值**，不可推翻上方优先级）
