# 用例说明书模板（cases.md）

每条 **matrix 行 / 每个 `test()`** 对应一节。`generate` 前必须齐全；`spec` 标题与 `test.step` 名与本文对齐。

路径：`{root}/explore/cases.md`（可与 `report.md` 同批）。

控件「怎么点」细节仍以 `report.md`「操作方式（已验证）」为准；本文写**用例级**故事。

---

## 文件头（必填）

```markdown
# 用例说明书

- domain: <biz>
- 批次: {yyyyMMdd-HHmmss}
- mode: smoke | full | scoped
- 本任务 scope: <维度/业务线/点名条件摘要>
```

---

## 单条用例块（复制填写）

```markdown
## <CASE_ID>

### 测什么
<一句话业务目标>

### 规则 / 数据条件
| # | 时间 | 聚合 | 指标 | 运算符 | 阈值 |
|---|------|------|------|--------|------|
| 1 | … | … | … | … | … |

其它前置（规则字段、开关、造数要点）写在表下。

### 怎么操作（执行步骤）
1. 准备：…
2. 建规则 / 开开关：…
3. 造数：（链到 seed-plan 或写清表/键）
4. 调 Job：…
5. 验记录：…

### 页面操作要点（explore）
- 引用 report 已验证路径；只列本用例关键控件（如加条件行尾 +）

### 预期终态
<唯一可判定结果；禁止「有则…无则…」>

### 产物引用
- matrix 行 id: …
- ruleId / ruleName: …
- seed: …
- spec: `test('<CASE_ID>: …')`
```

---

## 门禁

- `matrix.json` 每一行的 `id` 必须在 `cases.md` 有对应 `## <id>`  
- 每节必须含：**测什么**、**规则/数据条件**、**怎么操作**、**预期终态**  
- generate：`test` 名 = `<CASE_ID>: <短标题>`；`test.step` 名与「怎么操作」步骤一致（准备/建规则/开开关/造数/调Job/验记录/收尾等）  
- 缺说明书 → **禁止 generate**
