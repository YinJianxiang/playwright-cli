# 需求 MD 配图解析约定

## 收集范围

仅解析需求 Markdown 中**显式引用**的图片：

- `![alt](relative/or/absolute/path)`
- `<img src="...">`

路径相对 **md 文件所在目录** 解析。外链 URL：若无法拉取则记入缺失列表并停止（或询问用户改为本地路径）。

## 绑定上下文

1. 取该图片引用之前最近的标题（`#` / `##` / `###`）及同节列表/表格  
2. 从标题与列表识别选择因（如维度、业务线）与目标字段（如「指标」）  
3. 读图提取：下拉选项文案、表格列、红框/标注「新增」项  
4. 写入 `req-extract` 时同时保留「正文要点」与「图中要点」  

## 冲突

正文清单与截图枚举不一致时：

```markdown
- conflict: true
- 正文: A, B, C
- 图片: A, B, D
```

**询问用户**以哪边为准（或合并）后再写 `cases-ui` / `cases-flow` 期望值。禁止静默采信一边。

## 工具

Agent 使用 Read 工具直接查看本地 png/jpg/webp/gif。不在本仓库引入独立 OCR 依赖。
